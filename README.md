# TG Access Bot (aiogram)

Бот сфокусирован на двух задачах:
- onboarding/paywall через Telegram Stars (30 дней доступа);
- выдача одноразовой ссылки в приватный канал после активного доступа.

## Что есть в боте
- ⭐ Управление доступом: дисклеймер, покупка доступа, проверка статуса.
- 🔒 Выдача ссылки в закрытый канал (single-use invite).
- 🆘 Поддержка.
- 💬 Кнопка «Открыть чат аналитики» (внешний чат/канал с аналитикой, режимами и гайдами).

## Что вынесено отдельно
Аналитика, торговые режимы, стратегии и гайды больше не находятся в этом боте и должны жить в отдельном чате/канале аналитики.

## Запуск
1) `cp .env.example .env` и заполнить значения.
2) `docker compose up -d --build`
3) В support-группе отправить `/getchatid`, чтобы узнать `SUPPORT_GROUP_ID`.

## Переменные окружения
Дополнительно к стандартным параметрам:
- `ANALYTICS_CHAT_URL` — публичная ссылка вида `https://t.me/...` для кнопки «Открыть чат аналитики».
